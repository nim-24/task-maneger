# Менеджер задач

Небольшое настольное приложение на Python и Tkinter. Оно позволяет создавать задачи, менять их название, отмечать выполнение и удалять. Задачи хранятся в `data/tasks.json` рядом с приложением и остаются после перезапуска.

## Запуск

Нужен Python 3.10 или новее. Tkinter входит в стандартную поставку Python на Windows и обычно на macOS. На некоторых Linux его нужно установить отдельно (например, пакет `python3-tk`). Внешние Python-библиотеки проекту не нужны.

Откройте терминал в папке `task_manager` и выполните:

```powershell
python main.py
```

Если команда `python` не найдена в Windows, попробуйте `py main.py`.

## Как пользоваться

1. Введите название задачи. Описание и автора можно оставить пустыми.
2. Нажмите «Добавить задачу».
3. Выберите задачу в списке. Кнопка «Выполнено / вернуть» переключает статус.
4. «Изменить название» открывает небольшое окно редактирования.
5. «Удалить» просит подтвердить удаление.
6. Закройте окно и запустите `main.py` снова. Список загрузится из `data/tasks.json`.

Сохранение происходит автоматически после каждого изменения. Чтобы перенести список на другой компьютер, скопируйте `data/tasks.json` вместе с проектом.

## Как устроен проект

- `task.py` — класс `Task`: данные одной задачи (`id`, `title`, `description`, `status`, `author`, `created_at`) и преобразование в/из словаря.
- `storage_manager.py` — класс `StorageManager`: загрузка и сохранение JSON. Запись проходит через временный файл, чтобы не оставить частично записанные данные при прерывании.
- `interface.py` — класс `Interface` и классы виджетов `AppButton`, `AppEntry`, `AppLabel`, `AppListbox`. Интерфейс строит окна, читает ввод и передаёт действия фасаду; с JSON он не работает напрямую.
- `main.py` — класс `TaskManager` с CRUD-логикой и точка входа: создаёт главное окно, интерфейс, хранилище и запускает цикл Tkinter.

Поток добавления задачи выглядит так: кнопка в `Interface` проверяет название → вызывает `TaskManager.create_task()` → фасад создаёт `Task`, добавляет его в список и вызывает `StorageManager.save()` → интерфейс обновляет список на экране. Остальные операции проходят через фасад тем же способом.

## Как выполнить задание по шагам

1. Опишите сущность `Task` и поля, которые нужно хранить.
2. Вынесите чтение и запись JSON в `StorageManager`, чтобы интерфейс не зависел от формата файла.
3. Соберите интерфейс из отдельных виджетов в `Interface`; пусть он сообщает о действиях, но не меняет JSON сам.
4. Реализуйте CRUD в классе `TaskManager`, который находится в `main.py` (Create, Read, Update, Delete). Здесь «Read» — загрузка списка при старте и передача его для отображения. `main.py` также создаёт зависимости и запускает приложение.
6. Проверьте вручную: добавьте задачу, измените её, переключите статус, удалите другую задачу и перезапустите приложение. После перезапуска оставшаяся задача должна быть в прежнем состоянии.

`data/tasks.json` создаётся автоматически при первом сохранении. При отсутствии файла приложение начинает с пустого списка. Если JSON повреждён, приложение запускается с пустым списком и показывает сообщение в строке состояния; повреждённый файл следует восстановить вручную из резервной копии.
