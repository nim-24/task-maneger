# BUGFIX

## Исправлено

- Исправлено редактирование: раньше новая задача вставлялась неправильно, теперь заменяется выбранная строка.
- Удаление теперь работает с выбранной задачей, а не с текстом в поле ввода.
- После добавления, изменения и удаления список сразу обновляется.
- Изменения сохраняются в JSON, поэтому задачи остаются после закрытия программы.
- Пустые задачи не добавляются, а отсутствие выбора показывается как понятное сообщение.

## Возможные улучшения

- Проверять JSON на более сложные повреждения и предлагать восстановление файла.
- Добавить кнопку отмены последнего действия.
- Хранить задачи как объекты с отдельными полями: текст, дата и статус.
- Добавить подтверждение перед удалением задачи.
