# BACKLOG

## Сделано

- Интерфейс и логика приложения разделены по файлам.
- Задачи загружаются из `tasks.json` при запуске и сохраняются после изменений.
- Добавление пустой задачи запрещено.
- Для изменения и удаления нужно выбрать задачу в списке.
- Список задач сделан отдельным классом `AppListbox`.
- Кнопки и подписи сделаны отдельными классами `AppButton` и `AppLabel`.
- Добавление задачи работает по кнопке Enter.

## Можно добавить позже

- Отметку о выполнении задачи.
- Дату и приоритет задачи.
- Поиск по задачам.
- Подтверждение перед удалением.
