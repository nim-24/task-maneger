# Task Manager

Небольшой менеджер задач на Tkinter. Можно добавлять, изменять и удалять задачи. Список автоматически сохраняется в `tasks.json` рядом с файлами программы.

Запуск из этой папки:

```bash
python view.py
```

Файлы проекта: `view.py` — логика приложения, `Interface.py` — расположение элементов, `storage.py` — работа с JSON, `AppButton.py`, `AppLabel.py` и `AppListbox.py` — классы элементов интерфейса.
